# 산출물 해석: 신규 유저 반응 예측 모델 검증 결과 (비전공자용)

`evaluation.backtest`가 뽑는 결과를 처음 보는 사람도 이해할 수 있도록 정리한 문서.
실행 방법은 [`README.md`](../README.md) §2-4, 원리는 [`model_architecture.md`](model_architecture.md) 참고.
아래 수치는 2026년 6월 신규 유저 배치 기준 예시 — 새로 백테스트를 돌리면 숫자는 바뀐다.

```
python -m evaluation.backtest --config config/backtest.example.json
```

## 결론부터

모델이 "반응할 가능성이 높다"고 점수를 매긴 **상위 10% 그룹**은 실제로 광고에 반응한
비율이 전체 평균보다 **1.7배 높았다.** 반대로 "가능성이 낮다"고 본 **하위 10% 그룹**은
실제 반응률이 평균의 5분의 1 수준에 그쳤다. 즉 모델 점수로 유저를 줄 세우면, 그 순서가
실제 결과와 대체로 맞아떨어진다.

| 지표 | 값 |
|---|---|
| 분석 대상 신규 유저 | 11,729명 |
| 전체 평균 반응률 | 7.12% (835명) |
| 모델 상위 10% 그룹 반응률 | 12.1% (평균 대비 1.70배) |
| 모델 하위 10% 그룹 반응률 | 1.3% (평균 대비 0.18배) |

## 이걸 어떻게 확인했나

11,729명을 모델 점수 순으로 한 줄로 세운 다음, 앞에서부터 1,173명씩 10개 그룹으로
나눴다. **1번 그룹**은 모델이 "반응 안 할 것 같다"고 본 사람들, **10번 그룹**은 "반응할
것 같다"고 본 사람들이다. 그런 다음 시간이 지나 실제로 누가 광고에 반응했는지(전환 여부)
확인해서 그룹별 실제 반응률을 비교했다. 모델이 쓸모 있다면 그룹 번호가 올라갈수록(점수가
높을수록) 실제 반응률도 같이 올라가야 한다.

## 실무에 어떻게 쓰나

광고 예산과 노출 지면은 한정돼 있으니, 11,729명 전체에게 똑같이 노출하는 대신 모델
점수가 높은 사람부터 우선순위를 매겨 타겟팅하면 같은 예산으로 더 많은 반응을 끌어낼 수
있다.

- **상위 20%(그룹 9~10, 2,346명)만 타겟팅**했다면 261명이 반응해 반응률 11.1%(평균 대비
  1.56배)를 기록했을 것으로 추정된다.
- **하위 10%(그룹 1, 1,173명)**는 광고를 아예 보여주지 않아도 놓치는 반응이 15명뿐이라,
  이 그룹부터 예산을 줄이는 게 안전하다.

## 주의해서 볼 점

- **중간 그룹(2~6번)은 아직 촘촘하게 구분되지 않는다.** 그룹 3~5번 사이는 반응률이
  거의 같거나 살짝 오르내리는 정도라, 이 구간 안에서는 순위가 크게 의미 없다고 보는 게
  맞다. 모델은 양 극단(가장 반응 안 할 사람 / 가장 반응할 사람)을 가려내는 데는 강하지만,
  중간 단계의 미세한 순위는 더 다듬을 여지가 있다.
- **표본 크기를 재확인할 것.** 이번 분석 대상(11,729명)은 지난 파일럿(25,449명)보다
  작다 — 신규 유저 규모 자체가 줄었는지, 데이터 추출 조건이 달라졌는지 확인이 필요하다.
- **"반응"의 기준을 넓게 잡았다.** 여기서는 광고를 보고 최소한의 관심(참여 시작 단계,
  `--label-threshold 1`)을 보인 것도 반응으로 카운트했다. "끝까지 완료한 사람"(T4)처럼
  더 엄격한 기준으로 다시 보면 결과가 달라질 수 있다.
- **이 결과는 특정 시점의 스냅샷이다.** 새로운 유저 데이터와 실제 반응 데이터가 쌓일
  때마다 같은 방식으로 다시 확인해서, 모델이 계속 잘 맞는지 주기적으로 점검해야 한다.

## 용어

- **그룹(분위, decile)**: 모델 점수 순으로 유저를 10등분한 구간. 이 문서에서는 1~10번으로
  표기(1=점수 최하위 10%, 10=점수 최상위 10%).
- **반응(라벨/전환)**: `--label-threshold`로 정한 postback tier 이상 도달한 것. 기본값
  1은 T2(참여 시작) 이상.
- **배율(lift)**: 어떤 그룹의 실제 반응률 ÷ 전체 평균 반응률. 1.0보다 크면 평균보다 잘
  맞힌 것, 작으면 못 맞힌 것.
