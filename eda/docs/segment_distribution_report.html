해석 및 설계 시사점

1) 그룹마다 "쏠림의 성격"이 다르다

성별은 CV 0.51로 가장 균등하다 — 애초에 4개 값(여성/남성 × High/Low)뿐이고 서로 같은 모델링 스케일이라 자연스럽다. 반면 제품 관심사는 CV 1.45로 가장 쏠려 있다 — 418개 ID 중 상위 10%(약 42개)가 전체 device_cnt의 46%를 차지하고, 하위권 다수는 수백~한 자릿수 디바이스에 불과하다(최소값 1). 거주/콘텐츠 관심사/기타도 CV 1.27~1.32로 비슷하게 긴 꼬리를 보인다.

2) EmbeddingBag 어휘 설계에 주는 시사점

  • 제품 관심사·거주·콘텐츠 관심사·기타는 롱테일이 뚜렷하다 — 전체 ID를 다 살려서 개별 nn.Embedding 행을 주면, 파라미터 대부분이 관측 수가 극히 적은 꼬리 ID에 낭비된다. media_sequence가 이미 쓰고 있는 top-N vocab 절단 + 공용 UNK 버킷 패턴을 그대로 적용할 근거가 된다(model_architecture.md §2, MAX_VOCAB_SIZE=500 media 사례와 동일 논리).
  • 성별·연령대는 절단이 필요 없다 — ID 수 자체가 4~7개로 작아서, 있는 값 전부를 그대로 범주형 필드로 써도 임베딩 테이블 크기 부담이 없다.
  • "상위 10% ID 점유율"이 그룹별로 39~46%로 비슷하게 높다 — 그룹 크기(4개~418개)가 크게 달라도 "소수가 다수 점유율을 가져가는" 구조 자체는 6개 그룹 모두 공통적으로 나타난다. 즉 이건 특정 그룹만의 특성이 아니라 이 DMP 세그먼트 체계 전반의 성질로 봐도 될 것 같다.

3) 데이터 품질 참고

모집단: skp에 세그먼트가 하나라도 있는 device_ifa 전체(~53.3M, bid log 전체 모집단의 21.8%). 값 분포는 data/sample/세그먼트id별분포.csv(querys/propfit/10_group_value_distribution.sql 실행 결과) 기준.
