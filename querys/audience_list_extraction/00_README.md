# 특정 광고 관심 사용자 리스트 - 추출 쿼리

## 확정된 전제 (지금까지의 검증 결과)
- **광고 식별자**: `adspid`와 `cmp_no`/`ag_no`를 잇는 매핑 테이블이 존재하지 않음(확인 완료) → **`cmp_no`(+`ag_no`)를 "특정 광고" 식별자로 사용**
- **유저 식별자**: `bid_log_flatten.device_ifa` = `postback_log.ifa` (동일 식별자, 100% 오버랩 확인) → 기본 키로 사용. `req_user_id`는 92.8% 채워지고 거의 1:1이라 참고용 보조 키로 같이 표기
- **컴플라이언스 필터**: `req_ext_allow_user_data_collection = '1'`(데이터 활용 동의, 전체의 93%), `device_lmt`가 `'1'`(추적 제한 옵트아웃, 0.03%)이 아닌 것만 포함
- **디바이스ID 정제**: UUID 형식(`^[0-9a-fA-F-]{36}$`)이 아닌 값 제외 (placeholder/test 값 극소량 존재)
- **관심도 티어**: postback_log.log_type 기준
  - T1 노출만 (postback 없음)
  - T2 참여시작 (`i`, `v_start`)
  - T3 중간참여 (`v_mid` 이상)
  - T4 고관여/완료 (`v_complete`)
